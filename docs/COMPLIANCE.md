# NovelPhone 隐私政策与数据安全说明

> 上架合规资料（对应 PRD 8 风险表与 M4-16）。本文件是发布前提交应用商店与放置在应用内的合规文案来源；应用内"AI 功能首次联网前的告知"文案以本文 §3 为准。

## 1. 隐私政策

### 1.1 我们收集什么

**默认不收集任何数据。** NovelPhone 是本地优先的写作工具，不设账号体系，不接入广告或分析 SDK，不上传遥测。

- 作品、卷、章节正文、角色卡、章纲、灵感箱等创作数据：**仅保存在你的设备本地数据库**（SQLite），不离开设备。
- 应用设置（模型组、baseUrl、模型名、温度与输出上限、任务→模型映射、token 与处置率计数）：保存在设备本地。
- API Key：保存在**设备安全区**（iOS Keychain / Android Keystore），库中只保存引用标识，明文不落库、不导出、不上传。
- 应用锁（可选，默认关闭，ENH-25）：只调用操作系统提供的生物识别 / 设备凭证校验接口（`local_auth`），**不读取、不存储、不上传**指纹或人脸等生物识别数据；应用仅保存「应用锁是否开启」这一布尔设置。
- 截屏 / 最近任务缩略图保护（可选，默认关闭，ENH-26）：仅设置平台窗口标志（Android `FLAG_SECURE`）或在本应用退后台时覆盖一层遮罩（iOS），不采集、不上传任何屏幕内容；开启后系统截屏与任务切换器中的预览由操作系统置空或遮挡。iOS 无公开 API 阻止应用在前台时的主动截屏，此限制在设置页注明。
- 备份密码加密（可选，默认关闭，ENH-26）：加密在本机完成，密码仅保存在设备安全存储，**不上传、不写入备份文件、不写日志**；备份内容以 AES-256-GCM 密文（`.npbak`）保存，未设置密码或未开启时仍生成与旧版一致的明文 zip。
- AI 协作偏好（ENH-27 / ENH-28）：放弃 AI 结果时选择的原因计数与最近采纳片段，按作品保存在本机 `APP_SETTING`（`ai_feedback_<workId>` / `ai_adopted_samples_<workId>`，样本最多 5 条、单条最多 600 字），并另有作品级总开关 `ai_preferences_enabled_<workId>`（默认开启）；仅用于后续续写 / 改写的本地提示，**不随备份导出、不写日志、不上传 NovelPhone 服务器**。作者可在作品菜单查看、关闭或清空这些偏好（清空仅删原因与片段），永久删除作品时同事务清理上述三个设置键。使用续写 / 改写时，若开关开启，其中达到阈值的原因约束与截断后的采纳片段会随该次上下文直接发送给你配置的模型服务商。

### 1.2 何时会联网

只有你**主动触发**联网功能时才会联网——AI 功能（续写、灵感、AI 感检查的 LLM 深检、测试连接），或你在设置页「云备份」中**显式开启并触发**的云端备份：

- 网络请求**直连你自行配置的模型服务商**（OpenAI 兼容端点或 Anthropic Messages 端点，baseUrl 可自定义），NovelPhone 不设中转服务器，不经手你的请求。
- 传输内容**仅限该次 AI 请求所需的最小上下文**（由本地 ContextBuilder 按预算组装：系统指令、本章尾部正文、本章章纲、前 1–2 章摘要、相关角色卡、卷纲），不发送你的其他作品与无关章节。
- 续写 / 改写（含结果内多轮修改，ENH-27 / ENH-28）的请求还可能包含：**当前候选草稿、你的修改意见与创作中的作者协作偏好**（同一放弃原因累计 ≥ 2 次对应的约束、最近最多 3 条采纳片段，每条截断到 200 字；偏好总开关关闭时不发送）。这些内容只随该次请求发送，不经过 NovelPhone 服务器。
- 请求携带的 API Key 由你提供，仅用于向该服务商鉴权。
- **本地规则引擎的 AI 感检查完全离线**，绝不联网扫描你的正文。
- 若你主动配置了 **MCP 工具服务**（设置页「MCP 工具服务」），灵感类任务在 AI 决定调用其工具时，会把你自行配置的 MCP server 所需的参数经 `Authorization` 等自定义请求头直连该服务地址；不配置该功能则不产生此类请求。
- 若 MCP 服务选择 **OAuth 2.1（PKCE）** 认证，点「开始授权」后会打开**系统浏览器**直达该 MCP 服务的授权服务器（元数据发现、动态客户端注册与令牌交换都直连该服务器），授权完成后通过 `127.0.0.1` 本机回环回调把授权码换为令牌；NovelPhone 不设中转服务器，也不接收你的账号密码——登录与同意都在浏览器内由授权服务器完成。
- 若你在设置页「云备份」中开启，则在你手动触发（立即备份 / 刷新远端备份 / 从云端恢复）或开启「自动备份」后于应用启动 / 回到前台按所选频率自动触发时，会把整库备份 zip **直连你自行配置的对象存储**（S3 兼容：AWS S3 / 阿里云 OSS / 七牛云 Kodo / 腾讯云 COS / 华为云 OBS）上传或下载；若同时开启备份密码加密，上传内容为 `.npbak` 密文。NovelPhone 不设中转服务器。AccessKey / SecretKey 只存本机安全存储，不落库、不随备份导出。**该开关默认关闭；关闭时不联网、不产生任何云端请求。**

### 1.3 数据的删除与导出

- 卸载应用即清除本地数据库与安全区中的 Key / MCP 认证头 / OAuth 令牌。
- 应用内提供作品导出（txt / docx / markdown / EPUB）与整库 zip 备份（**备份不含 API Key**），你可自行保管与迁移。
- **系统级自动云备份已关闭**：Android 侧声明 `android:allowBackup="false"`，并在 Android 12+ 由 `dataExtractionRules` 将 cloud-backup 的全部数据域显式排除——作品数据不会进入 Google Drive 等系统云备份，卸载后也不存在「云端恢复回来」的隐藏路径；Android 12+ 的换机设备直传（D2D）保留，数据仅在用户自己的两台设备之间直接迁移、不经过云端。

### 1.4 第三方

数据传输到你所配置的模型服务商后，其处理方式适用该服务商的隐私政策。请自行确认其条款。（本应用不集成任何第三方 SDK。）

### 1.5 未成年人

本应用为通用写作工具，不面向未成年人专门设计，也不主动收集未成年人个人信息。

## 2. 数据安全说明

| 项 | 做法 |
|---|---|
| 正文与设定数据 | 本地 SQLite（drift），离线可用；不参与任何出网请求，除你在 AI 请求中主动包含的当前上下文 |
| API Key | 仅存 flutter_secure_storage（Keychain / Keystore）；库中只存 `apiKeyRef` 引用；删除模型组时同步清除安全区 Key |
| MCP 认证头 | 与 API Key 同策略：只存 flutter_secure_storage（`mcp_server_<id>`），配置 JSON 仅存 URL / 名称 / 工具白名单 / OAuth client_id 与 scope；删除 MCP 服务时同步清除 |
| MCP OAuth 令牌 | access / refresh 令牌与过期时间以 JSON 只存 flutter_secure_storage（`mcp_oauth_<id>`），不落库、不随备份导出、不写日志；授权走 PKCE（S256）、无客户端密钥落地，令牌过期自动用 refresh_token 续期，刷新失败提示重新授权；删除 MCP 服务或「清除授权」时立即删除 |
| 备份文件 | zip 导出时过滤 Key 字段；恢复后需重新填写 Key。开启备份密码加密（ENH-26）后导出 `.npbak` 密文：PBKDF2-HMAC-SHA256 210,000 次 + 随机 16 字节 salt 派生密钥，AES-256-GCM 认证加密（随机 12 字节 nonce / 16 字节 MAC）；密码至少 8 位、仅存 flutter_secure_storage（`backup_passphrase`），不写日志；密码错误或文件被篡改时拒绝恢复并提示「密码错误或备份文件已损坏」 |
| 截屏保护（ENH-26） | 默认关闭；开关状态存 APP_SETTING（`screen_protection_enabled`），不随备份导出；Android 仅增删窗口 `FLAG_SECURE`，iOS 退后台时叠加遮罩，不采集屏幕内容、不申请额外权限；关闭后立即恢复系统截屏能力 |
| 云备份凭证 | 与 API Key 同策略：AccessKey / SecretKey 仅存 flutter_secure_storage；配置 JSON（服务商 / endpoint / region / bucket / 前缀 / 保留份数）存 APP_SETTING，不含凭证、不随备份导出 |
| 作品问答历史 | 按作品存 APP_SETTING（`work_chat_<workId>`，最多保留 40 轮），仅保存在本机、不随备份导出、不写日志；在作品问答页清空后立即删除。使用作品问答时，最近对话会作为上下文直接发送给你配置的模型服务商 |
| AI 协作偏好（ENH-27 / ENH-28） | 按作品存 APP_SETTING（`ai_feedback_<workId>` 放弃原因计数、`ai_adopted_samples_<workId>` 最近采纳片段，最多 5 条 / 单条 600 字；`ai_preferences_enabled_<workId>` 总开关，默认开启），仅保存在本机、不随备份导出、不写日志；可在作品菜单查看 / 关闭 / 清空，永久删除作品时同事务清理三个键；续写 / 改写时若开关开启，高频原因约束与截断后的片段（最多 3 条 / 每条 200 字）随上下文发送给用户配置的模型服务商；无高频原因、无样本或开关关闭时不注入 |
| 应用锁（ENH-25） | 默认关闭；开关状态存 APP_SETTING（`app_lock_enabled`），不涉及任何生物特征数据；解锁时由系统 BiometricPrompt / LocalAuthentication 完成校验并把结果返回应用，生物识别模板由操作系统保管，应用不接触、不记录、不上传；Android 仅声明 `USE_BIOMETRIC` 权限 |
| 出网面 | 除用户配置的模型服务端点、MCP 服务地址（可选）与用户开启并触发时的云备份对象存储地址外，无任何出网请求（无更新检查、无遥测、无广告） |
| 系统备份 | Android `allowBackup="false"` + Android 12+ `dataExtractionRules`（cloud-backup 全数据域排除）；换机设备直传（D2D）按系统默认保留、不经云端 |
| 传输内容 | 最小可用上下文；本地规则引擎检查不联网 |

## 3. AI 功能首次联网前的告知文案

在用户**首次**触发任一 AI 联网功能前，弹出一次性确认对话框，文案如下：

> **使用 AI 前请知悉**
>
> 你的作品正文与设定默认只保存在本机。当你使用 AI 功能时，应用会把你自行配置的模型服务商所需的最小上下文（当前章节内容、章纲、相关角色卡等）通过网络**直接发送给你配置的服务商**，不会经过 NovelPhone 的服务器。
>
> 你的 API Key 保存在设备安全区，不会上传。
>
> 点击"我已了解"表示你已知悉并同意上述传输行为。

按钮：「我已了解」（继续并记住选择） / 「取消」（不发起请求）。

确认结果记录在本地设置（`ai_notice_ack`），此后不再重复弹出；用户可在设置中清除应用数据以重置。

## 4. 应用商店上架资料要点

- 应用名称：NovelPhone
- 一句话简介：本地优先的手机小说写作工具，AI 辅助灵感与续写，稿子不出设备。
- 关键词：小说写作、写作工具、AI 续写、灵感、本地、隐私
- 描述要点：
  - 作品数据全本地，离线写作，杀进程不丢稿；
  - AI 续写、灵感、AI 感检查（本地规则引擎 + 可选 LLM 深检）；
  - 自带 API Key，直连主流模型服务商（OpenAI 兼容 / Anthropic），不经中转；
  - 不收集数据、无广告、无遥测。
- 隐私标签（Data Safety）填报口径：
  - 收集/共享：**无**（应用不收集任何数据）；
  - 用户主动触发的 AI 请求会将被选中的上下文发送至用户自行配置的第三方模型服务商，此行为由用户主动发起且由其自持凭证；
  - 数据加密：API Key 使用平台安全存储加密保存；
  - 数据删除：卸载应用即删除本地数据（系统自动云备份已关闭，不存在经 Google Drive 的云端恢复）；
  - 备份 / 迁移：系统云备份关闭；Android 12+ 换机设备直传（D2D）保留；应用内备份（文件导出 / 自持对象存储）均由用户主动触发。
- 需要声明的权限：网络访问（仅用于用户主动触发的 AI 请求与用户开启并触发的云备份）与生物识别（`android.permission.USE_BIOMETRIC`，仅在你开启应用锁并解锁时由系统弹出校验；拒绝该权限不影响写作与 AI 功能）。Android 侧须在 `android/app/src/main/AndroidManifest.xml` 声明 `android.permission.INTERNET`——Flutter 模板只在 debug/profile 清单里声明，release 构建若不补齐该权限，AI 与云备份的全部联网能力会被系统阻断；应用锁还要求 `MainActivity` 继承 `FlutterFragmentActivity`。iOS 使用 Face ID / Touch ID 时在 `Info.plist` 提供 `NSFaceIDUsageDescription`，生物识别由 LocalAuthentication 框架完成。
- 隐私政策 URL（商店必填）：`https://github.com/wly2lcl/NovelPhone/blob/main/docs/PRIVACY.md`——[PRIVACY.md](./PRIVACY.md) 是对外的独立隐私政策（中英双语、含生效日期与联系方式），与本文件 §1 保持一致；应用内「关于」页可直接打开该外链。数据安全表单与商店资料详见 [RELEASE.md](./RELEASE.md)。
